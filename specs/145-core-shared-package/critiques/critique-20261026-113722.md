## Executive Summary

Records and plan agree: adrkit reports no departures. Ten defects block implementation. Five are in the new release
rule: it reads Ready from any project and actor, counts edited comments, decides over a different snapshot than it
writes, and lets a reader that cannot see the board answer differently from one that can. Five are elsewhere: module
calls take no repo, the head's push time has no source, Codex can be asked twice per head, the key gate trusts the
file rather than the policy in effect, and the dependency guard loops a Stop hook. All but one have a single correct
fix inside core. The one that does not needs the user: which project is the board (Q1).
