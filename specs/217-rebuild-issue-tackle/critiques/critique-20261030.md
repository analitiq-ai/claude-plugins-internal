## Executive Summary

Problem is real and evidenced (accepted builder ADR-0002–0004 vs `issue-tackle/SKILL.md` on main). Plan's split, with
facts read through core, a pure `decideStep` and the step printed as JSON, is sound and testable. Four must-address
items: (1) builder composes PR findings by loading validator packages from a model-run script, but validator tokens are
keys only hooks read (root ADR-0008 d4), so any key-reading package makes every attested step exit 2;
(2) launching `reviewer:review-round` with no `spec` is refused by reviewer's gate today (README §5), and no
dependency ships reviewer ADR-0014 d1; (3) a story whose branch is on GitHub but not in the local worktree
dead-ends (no write path creates the worktree; `github ≠ local` stops); (4) the plan splits US4 across two PRs
and runs it first, while spec keeps it one P2 story, so story issues, `tasks.md` blocks and tick grading misalign.
