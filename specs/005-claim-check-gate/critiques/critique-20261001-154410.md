### 💡 Recommendations
- **P3:** The spec says merge commits are skipped, but nothing in the plan detects one. Check for `MERGE_HEAD`, `CHERRY_PICK_HEAD` and `REVERT_HEAD`.
- **P4:** Nothing measures false refusals after launch, though blocking starts with unmeasured verdicts. Use the ledger to track contests upheld vs. overturned, unlock count and cost per commit, and set a threshold that triggers a rethink. SC-002 depends on the model, so it can't run in CI; mark it as a manual acceptance run.
- **E5:** `merge`, `cherry-pick`, `rebase --continue`, `am`, `commit-tree`, `bash -c` and git aliases also create commits and aren't intercepted. List them in the plan's Limits.
- **E7:** Skip files that `.gitattributes` marks as binary or generated.
- **E8:** Key the claim cache on the full sentence, not just the quote. Don't cache `CORRECT` for "every/only/exactly" claims: a new file can break them without touching any file the verdict cited.
